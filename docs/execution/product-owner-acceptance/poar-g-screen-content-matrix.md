# POAR-G — Screen Content Matrix

Each row records present orientation/state/action language, the material gap, and the target content pattern. Screen families follow POAR-A and the current route registry.

## Screen-level acceptance rule

Each screen must answer, within its first meaningful viewport: where am I, why does this matter now, what is true, who owns the next step, what can I do, and what happens next. Secondary technical provenance must remain available without replacing that primary narrative.
