## Golden-path rebuild order

1. Establish state projection and navigation contracts.
2. Rebuild client Review → Credit Center → Plan.
3. Rebuild Cards → Round → Strategy → Scheduling → Live → Post-Round.
4. Rebuild Consultant Dashboard → Queue → Client 360 → domain workbenches.
5. Rebuild Admin identity/security and commerce operations.
6. Rebuild Admin platform operations and governance.
7. Run interruption, narrow viewport, keyboard, stale/reconnect and cross-role handoff acceptance.

No journey is accepted solely because its endpoints render. Acceptance requires understandable origin, preserved context, a truthful next action, recoverable interruption, authority-valid destination and a coherent visual story.
