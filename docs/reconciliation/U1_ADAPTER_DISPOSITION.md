# U1 closeout scope and adapter disposition

Authority: U0–U1 package U1.2/U1.6 and legacy rules; final Portal QA Batch 2 CP-PL-01. These permit compatibility reads while requiring the coordinated Plan experience. The following is an implementation disposition under that authority, not a user approval of final U4 domain parity.

| U1 surface/contract | Implemented basis | Limit and owning migration |
| --- | --- | --- |
| Home/Center/Plan focus and currentness | One server composition; safe source identifiers, server refresh boundaries, immutable publication currentness | Review/Profile U3; global Plan U4; Round/Live sources U6 |
| Available actions and blockers | Plan command affordances from existing availability selector; command revalidation retained. Major restrictions, blocked Round, stale Strategy and paused/waiting Live are read from their scoped sources. | Review start eligibility remains on its sole eligibility screen; service purchase/start permissions remain service-owned. A focus navigation link is never purchase/start/execution permission. U3/U6/U7 replace owning adapters. |
| Plan Overview/Actions/Guidance | Existing published PlanVersion/PlanItem read, Action-only counts, exact item/dependency/history and safe response forms | U4 replaces the legacy per-publication model with global CreditPlan/PlanItem; no PlanPath expansion. |
| Decisions | Published Review recommendation explanations plus effective/superseded Major coordination decisions, bounded to 20 of each source, with provenance and historical qualification | This view is a source-linked U1 bridge. It does not create PlanDecision records or interpret activity logs. Global Plan-owned decision authoring and other service decision feeds are U4/U6 work. |
| Nurture | Explicit NURTURE purpose on the current published Plan, rendered through the same roadmap/item controls | No synthetic NurturePeriod lifecycle. Empty state means no currently published Nurture Plan, not absence of all historical nurture work. Unified global Nurture policy/history is U4. |

No empty blocker array means universal eligibility. No action affordance substitutes for scope, current-version, form validity, prerequisite or consequential command checks. Private staff rationale, processing traces and draft decision content are excluded from the new reads.

U1 screen acceptance must still be supported by state/interaction/browser and regression evidence. These documented migration limits are not grounds for marking a failed U1 test or an unimplemented current behavior as complete.
