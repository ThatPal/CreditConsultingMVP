## Operational authority map

- Review status and published review facts: `CreditReview` and immutable `CreditSnapshot` children.
- Client global plan state: `PlanAction` during transition, with `kind` distinguishing Action, Guidance, and Milestone.
- Consultant queue: future `AttentionItem`; current `WorkItem` is explicitly classified as projection or legacy compatibility.
- Support conversation: `SupportCase` / `SupportMessage`; it does not own plan or workflow truth.
- User-facing information: `Notification`; realtime events only invalidate/read canonical state.
- Seasonal workflow: `ApplicationCycle` until the canonical seasonal state machine migration; display identity is now separate from `cycleNumber`.
- Commerce rights: `ServiceEntitlement` and append-only `ReviewCreditTransaction`; `Payment` records verified financial events.

## No-loss principles

All Sprint 0.2 schema changes are additive. Historical migrations, IDs, purchases, plans, reviews, files, cycles, and provider values remain intact. Backfills append rights derived from already-paid purchases and never invent provider transactions.
