# Theme preview and adoption workflow

Preview: http://127.0.0.1:5195/reference/theme-preview/index.html

The user approved this direction for current use on September 22, 2026. It has been applied to the shared application palette and structural surfaces on `ui/credit-profile`.

For future changes:
1. Explore colors, treatments and representative components on this standalone page.
2. Obtain user approval here before applying the proposed changes across the app.
3. Promote approved treatments to shared theme tokens and scoped light focus styles; preserve existing layout, behavior and data contracts.
4. Verify contrast, targeted components, loading states, desktop and mobile; retain app screenshots as adoption evidence.

This HTML/CSS/JS page is not imported by the app. All values and interactions are illustrative, with no account API calls. Blue/violet lead on dark surfaces; teal/mint lead on light focus surfaces. Its controls do not record product approval.

The application action gradient uses slightly deeper endpoints than the initial concept to retain 4.5:1 white-label contrast. The preview now reflects those accessible endpoints.

Application evidence: `docs/evidence/theme-adoption/`.
